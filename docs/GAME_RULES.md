# FAREEG AI — Configurable Traditional Game Rules

Rules for Emirati heritage games vary by family tradition and emirate region. The scoring engine isolates scoring from computer-vision detection.

## 1. Football (كرة القدم)
- **Goal Scored**: +1 Point (Ball completely crosses plane between posts)
- **Penalty Awarded**: 0 Direct Points (Spot kick opportunity)
- **Tournament Points**: Win = 3 pts, Draw = 1 pt, Loss = 0 pts

## 2. Al Teela (التيلة - Traditional Marbles)
- **Marble Knockout**: +1 Point (Shooter strikes target marble out of circle ring)
- **Khoor (Center Hole Entry)**: +2 Points (Teela settles directly inside target depression)
- **Foul**: Shooter hand crosses ring boundary before release

## 3. Al Dama (الدامة - Traditional Board Game)
- **Piece Captured**: +1 Point (Opponent draught piece jumped orthogonally)
- **King (Sheikh) Promoted**: +2 Points (Piece reaches opposing back rank)
- **Chain Multi-Capture**: +3 Points (Consecutive jumps in single turn)

## 4. Al Laqaf (اللقف - Five Stones Dexterity)
- **Stage Completed**: +1 Point (Toss leading stone, gather grounded stones, catch falling stone)
- **The Claw / Back-of-Hand Flip**: +2 Points (Catch stones on dorsal hand and scoop cleanly)
- **Fault**: Dropped pebble or touching adjacent ground pebble

## 5. Qif (قِف - Halt & Freeze Tag)
- **Freeze Tag Validated**: +1 Point (Tagger touches runner moving after "Qif!" call)
- **Statue Hold**: +1 Point (Runner maintains motionless posture for 5 seconds)
